# StokSegar API

Backend RESTful API untuk manajemen inventaris bahan segar UMKM Lapak Steak.

## Prasyarat Sistem
- Node.js (v24.x atau LTS terbaru)
- Git

## Panduan Menjalankan Skrip
Jalankan skrip kalkulasi sisa stok dari root folder:

```powershell
node hitungStok.js
```
